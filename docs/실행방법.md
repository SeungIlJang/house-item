# 실행 방법 (집안의모든것 / home-items)

로컬에서 백엔드(Worker)와 앱을 띄우고, 검사·테스트까지 하는 절차입니다.

- 백엔드: `worker/` (Cloudflare Workers + Hono, 로컬 D1·R2, 포트 8787)
- 앱: `home-items-app/` (Ionic Vue, 포트 5173)

> 이전 FastAPI + PostgreSQL 실행 절차는 백엔드 삭제와 함께 없어졌습니다. 필요하면 git 기록을 보세요.

---

## 0. 사전 준비 (최초 1회)

| 도구 | 확인 명령 | 비고 |
|------|-----------|------|
| Node.js 22 이상 | `node --version` | Wrangler 4 가 Node 22 를 요구합니다 |

nvm-windows 사용 시:

```bash
nvm use 22.18.0
```

### Worker 비밀값 파일

```bash
cd worker
cp .dev.vars.example .dev.vars
```

`.dev.vars` 의 `JWT_SECRET_KEY` 를 아무 긴 문자열로 바꿉니다.
로컬에서 소셜 로그인까지 해 보려면 구글·카카오 키도 채우고, 각 개발자 콘솔에
`http://localhost:8787/api/v1/auth/{google|kakao}/callback` 을 리다이렉트 URI 로 등록합니다.

## 1. 백엔드 실행

```bash
cd worker
npm install          # 최초 1회 / 의존성 변경 시
npm run db:local     # 로컬 D1 테이블 생성·최신화 (마이그레이션 추가 시)
npm run dev          # http://localhost:8787
```

확인: `http://localhost:8787/health` → `{"success":true,...}`

로컬 데이터는 `worker/.wrangler/` 에 저장됩니다. 지우면 초기화됩니다.

## 2. 앱 실행 (브라우저)

```bash
cd home-items-app
npm install
npm run dev          # http://localhost:5173
```

개발 모드에서는 API 주소가 자동으로 `http://localhost:8787/api/v1` 입니다.
운영 API 를 보면서 화면만 고치고 싶다면:

```bash
VITE_API_BASE_URL=https://home-items-api.season-masil.workers.dev/api/v1 npm run dev
```

(운영 API 의 CORS 는 앱 출처만 허용하므로 브라우저에서는 막힐 수 있습니다.)
